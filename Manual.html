Getting Started

Move Plattersong to Applications and open it. In Settings, choose a physical disk, enable it and choose Start Monitoring. Close Settings when finished. Plattersong stays in the menu bar and remembers whether monitoring was on or off. Closing Settings does not stop it; Quit Plattersong does.

Plattersong monitors physical disks whose drivers expose read and write counters. It does not show file names or track which app is responsible. Volume partitions sharing one disk have one sound. Cached reads and delayed writes may not trigger at the same time as the operation in an app. Network shares and disk images are not monitored.

Disk Sounds And Controls

Each disk has its own enable setting, volume, stereo pan, bass, midrange and treble. Adjust EQ around the flat midpoint to distinguish disks. Start with Preview Read and Preview Write, then choose Start Monitoring. Reset Mix restores that disk's volume, pan and EQ without disabling it.

Disconnecting an external disk does not stop monitoring other disks. When the same disk reconnects, Plattersong resumes using its saved mix. Some adapters do not expose a serial number or media identifier; reconnect those to the same port to retain their mix.

Keyboard And VoiceOver

  • Open the Plattersong menu bar item and choose Settings. Command+Comma opens Settings while Plattersong is active.
  • Tab and Shift+Tab move between controls. On a slider, use arrows for small changes, Page Up or Page Down for larger changes, and Home or End for the limits.
  • Control+Shift+K toggles monitoring globally by default. Choose Change Shortcut to use another combination, or Clear to remove it. Escape cancels recording a shortcut.
  • Start/stop feedback can be spoken, a chime, or silent. The menu bar item also exposes whether monitoring is on.
  • F1 opens help for the focused control. Control+F1 opens the GitHub project; Command+F1 is an alternative if macOS reserves Control+F1. You may need Fn on a keyboard with media keys.
  • Escape or Command+W closes Settings. Command+Q quits.

Open At Login And Updates

Turn on Open at login in Settings. If macOS asks for approval, allow Plattersong in System Settings under General, Login Items. At sign-in, the app starts in the menu bar and restores your previous monitoring state.

Choose Check for Updates in the Plattersong menu, or press Shift+F1 while Settings is active. Review the available version and its notes before installing. An update must pass the app signature check before it can replace the installed app. Settings are stored separately and retained.
